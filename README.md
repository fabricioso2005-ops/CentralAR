# CentralAR

Ferramentas comerciais da AR Incorporadora para os gerentes que atendem imobiliárias e corretores autônomos.

| pasta | o quê |
|---|---|
| `app/` | **App Central de Atendimento** (PWA + Supabase): login próprio por gerente, base separada de imobiliárias, corretores, contatos e visitas; o gestor vê tudo. |
| `supabase/schema.sql` | Banco de dados e regras de segurança do app. |
| `docs/INSTALACAO.md` | Passo a passo para colocar o app no ar. |
| `central/` | Versão anterior, como artefato do Claude (login pela conta do Claude). |
